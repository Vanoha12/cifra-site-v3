# Фотоцентр «Цифра» — site-v3

Демонстрационный концепт витрины фотоцентра: главная страница, рабочие карточки
услуг и корзина. Без сборки и внешних библиотек.

## Онлайн-демо

https://vanoha12.github.io/cifra-site-v3/

## Как открыть

Можно открыть `index.html` двойным кликом. Для проверки загрузки файлов удобнее
локальный сервер:

```powershell
python -m http.server 8123
```

Затем открыть `http://127.0.0.1:8123/`.

## Что внутри

- `index.html` — витрина, модальные окна, корзина и форма заказа.
- `politika.html` — демонстрационная политика конфиденциальности.
- `assets/css/styles.css` — стили и адаптив.
- `assets/js/catalog-data.js` — карточки услуг.
- `assets/js/app.js` — витрина, корзина, заказ, адреса.
- `assets/js/crop.js` — редактор кадра.
- `assets/js/archive.js` — сборка ZIP-архива заказа.
- `assets/img/` — авторские SVG-иллюстрации услуг и схема салонов.

## Демо-режим

- Заказ и файлы никуда не отправляются.
- После оформления формируется ZIP-архив: обрезанные фотографии, исходные файлы
  документов и `order.txt` с составом заказа.
- Политика конфиденциальности — демонстрационный документ. Перед реальным
  запуском замените его на юридически проверенную версию.

## Изображения

Все иллюстрации услуг и схема салонов нарисованы специально для концепта в SVG.
Их можно свободно заменить на фотографии салона и продукции.
